# Mini Proyecto Ágil

En este proyecto subí el código de una calculadora sencilla en Python y apliqué buenas prácticas de desarrollo ágil e integración continua.

## Prácticas que utilicé:

1. Estándares de Código (PEP 8):
Acomodé el código de la calculadora para que fuera limpio y fácil de leer, respetando las reglas de formato de Python. Esto evita que el código sea confuso o que tenga errores de sintaxis simples.

2. Pull Request y Code Review:
En lugar de subir los cambios directo a la rama principal, trabajé con ramas secundarias y simulé una revisión de código antes de hacer la unión (merge). Esto ayuda a revisar que todo funcione bien y evita fallos cuando se trabaja en equipo.

## Mi reflexión:
Aprender a trabajar con ramas y hacer revisiones de código antes de juntar todo evita el problema del "Big Bang", donde se intenta unir mucho código al final y salen miles de errores. Es mucho más fácil resolver pequeños detalles paso a paso.
